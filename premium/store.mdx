## Gift a friend

<Steps>
  <Step title="Pick Gift">
    Open the product and choose **Gift**. For Premium you can go straight to [love.rip/pricing/premium?for=gift](https://www.love.rip/pricing/premium?for=gift).
  </Step>
  <Step title="Choose who gets it">
    Search for the member. You can't gift Premium to someone who already has it.
  </Step>
  <Step title="Set the quantity and pay">
    For tokens, quantity is how many you're gifting.
  </Step>
</Steps>

<Tip>Gifting Premium earns you the **Gifter** badge.</Tip>

## Fund a giveaway

Buy prizes for a giveaway in a Discord server. Choose **Giveaway** and set the quantity to the number of winners. After you pay, you get a giveaway code by email. Then run `/giveaway redeem` with that code in a server that has the love.rip bot. See the [Discord bot](/discord-bot/commands) page.

## Cart and codes

- **Cart:** add several things and pay at once at [love.rip/pricing/cart](https://www.love.rip/pricing/cart). Up to 20 of each item.
- **Codes:** enter a discount or affiliate code in the **Code** box for 5% off.
- **Payment:** card, through secure Stripe checkout.
