# love.rip docs

Documentation for [love.rip](https://www.love.rip), built with [Mintlify](https://mintlify.com).

## Local preview

From the repo root, where `docs.json` lives:

```bash
npx mint dev
```

Open the preview at `http://localhost:3000`.

## Screenshots

Put screenshots in `images/` using the filenames listed in `images/README.md`.
